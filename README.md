Heimdall

Heimdall is an AI-powered design-to-code engine built on the agentic capabilities of Mistral AI and powered by the Devstral coding agent.

Heimdall turns rough hand-drawn sketches into polished UI mockups and fully functional applications — in a single seamless pipeline.

 What It Does
Upload a sketch
Snap a photo of your napkin drawing, whiteboard idea, or rough paper wireframe.

AI UI Interpretation
Heimdall analyzes your sketch and generates a clean, probable UI layout.

Autonomous App Generation
Using Devstral, the system converts that UI into working application code.

Interactive Customization
Chat directly with the coding agent to:

Refine UI components

Add features

Modify logic

Iterate instantly

From concept → mockup → production-ready prototype — all in one flow.

🧠 Architecture Overview

Heimdall runs as a unified AI pipeline:

Vision Model → Interprets sketch structure and layout intent

UI Generator → Produces structured UI components

Agentic Code Generator (Devstral) → Builds the working app

Conversational Agent Layer → Enables iterative refinement

The entire process is automated but remains fully interactive.

💡 Why Heimdall?

Eliminates the gap between idea and implementation

Reduces design-to-development friction

Enables non-technical founders to prototype instantly

Keeps developers in the loop with full code access

Real-time conversational editing

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
